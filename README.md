# Team Markers

Клиентский Fabric-мод для Minecraft 1.21.11.

Что делает:

- показывает плавающую метку игроков из той же scoreboard-команды;
- выводит имя и расстояние до тимейта поверх стен;
- держится над тимейтом, даже когда он двигается;
- работает на расстоянии до 5000 блоков;
- включается только на клиенте, где установлен этот мод;
- обновляет координаты меток 2 раза в секунду;
- открывает меню клавишей `Right Shift`.

## Установка

1. Установить Fabric Loader для Minecraft 1.21.11.
2. Установить Fabric API для 1.21.11.
3. Положить собранный `team-esp-1.0.0.jar` в папку `.minecraft/mods`.
4. Запустить игру с профилем Fabric.

Серверная установка не требуется: мод не меняет сервер, не отправляет команды и не показывает метки игрокам без мода. Для определения союзников сервер должен использовать обычные scoreboard-команды Minecraft (`/team`).

## Сборка

Нужен JDK 21 и Gradle 8.x:

```text
gradle build
```

Готовый JAR появится в `build/libs`.

## Сборка через GitHub

Загрузи содержимое проекта в новый GitHub-репозиторий. Workflow в `.github/workflows/build.yml` автоматически соберёт мод. После завершения открой `Actions`, выбери последний запуск и скачай artifact `team-esp-1.21.11`.
